# Line Signal

Open index.html locally, or serve the repository as static files. All articles, citations and photographs are in the HTML. The listening instruments run in the browser. No build, application server, third-party scripts, remote media or downloaded audio files are required.

## GitHub Pages

The workflow in .github/workflows/pages.yml publishes main when the destination repository uses **Settings → Pages → Build and deployment → GitHub Actions**. Paths are relative for project sites. Verify the deployment using the github-pages environment URL after pushing.

## Editorial and signal sources

Each chapter links its references. Open **Signal notes & sources** within a player for the reconstruction method, omitted signaling and transcript. All playback is manually initiated. Each chapter stage can be selected while paused. See DEVLOG.md for verification history and assets/CREDITS.md for photograph licenses.
